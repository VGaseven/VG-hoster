# BizData Sandbox

**Learn the data workflows business analysts actually use — SQL, R and EViews — inside VS Code, with live what-if simulators.**

BizData Sandbox is a learning environment for business, finance and economics students. Each module starts from a
realistic business problem, walks you through the professional workflow step by step (query → prepare → model), and
lets you move sliders to see what running that code against a real database would return.

No database, R installation or EViews licence is required to learn: the simulator computes the results for you.
When you're ready, open any snippet in a real editor tab and run it against your own data.

---

## Why business students use it

- **See the whole pipeline, not just one tool.** Real analytics work chains SQL (get the data), R (clean, test, model)
  and, in economics and finance, EViews (econometrics). Each module shows how the hand-offs work.
- **Connect code to business decisions.** Every scenario ends in a number a manager cares about: the maximum you can
  pay to acquire a customer, the days of cash runway, next year's inflation for contract indexation.
- **Build intuition with what-if sliders.** Change retention, margins, volatility or ARIMA coefficients and watch the
  KPIs, chart and result table update instantly — and the code update with your assumptions.
- **Professional-grade code.** Snippets follow conventions used in corporate data teams: CTEs and window functions in
  SQL, tidyverse pipelines in R, and EViews programs with identification, estimation, diagnostics and forecasting.
- **Fits your editor.** The UI follows your VS Code theme (light, dark and high contrast).

## Modules

| Module | Languages | Business question | What you learn |
| --- | --- | --- | --- |
| 🛒 **Marketing Analytics** | SQL · R | What is a new customer worth, and what's our maximum acquisition cost? | Cohort analysis, retention, discounted Customer Lifetime Value (CLV) |
| 🏦 **Corporate Finance** | SQL · R | Will we need to draw on the credit line in the next two weeks? | General-ledger queries, running balances, moving-average cash-flow forecasting, runway |
| 📈 **Macro Forecasting** | SQL · R · EViews | What will inflation be over the next 12 months? | Pulling CPI vintages, ADF unit-root tests, ACF/PACF, ARIMA(1,1,1) estimation and forecasting |

### SQL features
- Common table expressions (CTEs) for readable, staged queries
- Window functions: `FIRST_VALUE`, running `SUM() OVER`, named `WINDOW` clauses
- Calendar spines with `generate_series` so days without postings still appear
- Latest-vintage selection for revised macroeconomic data

### R features
- `DBI` database connections and query hand-off from `.sql` files
- `dplyr` pipelines for cohort and ledger transformations
- `zoo::rollmeanr` moving averages and forecast intervals
- `tseries::adf.test`, `forecast::Arima` and residual diagnostics
- `ggplot2` charts and CSV hand-off to EViews

### EViews features
- Workfile creation and CSV import
- Unit-root tests (`uroot`), correlograms (`correl`)
- ARIMA estimation with `ls d(lcpi) c ar(1) ma(1)`
- ARMA root checks, residual Q-statistics and normality tests
- Forecasting the level of the series with 95% confidence bands and frozen graphs

## Getting started

1. Install **BizData Sandbox** from the Visual Studio Marketplace (or from a `.vsix` file — see below).
2. Open the Command Palette: `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (macOS).
3. Run **BizData: Open BizData Sandbox**.

## How to use it

1. **Pick a module** with the buttons in the top-right corner.
2. **Read the scenario** on the left. The numbered workflow shows which language handles each step — click a language
   badge to jump to that step's code. Expand **Key concepts** for definitions.
3. **Study the code** in the SQL / R / EViews tabs. Tabs that don't apply to the module are disabled.
4. **Move the sliders** in the Live simulator. KPIs, the chart and the results table update instantly, and parameters
   in the code (for example the R assumptions or the EViews forecast sample) update to match.
5. **Experiment.** Edit the code freely; once edited, sliders stop rewriting that snippet. Press **Reset** to restore the
   reference solution.
6. **Take it further.** Use **Copy** or **Open in editor** to move a snippet into a real file and run it against your
   own database, R session or EViews installation.

Your module, tab, slider positions and edits are kept while the panel is open, even if you switch tabs in VS Code.

## Requirements

- VS Code 1.85 or later.
- Optional, to run the snippets for real: a PostgreSQL database, R (4.1+ for the native `|>` pipe) with the packages
  `DBI`, `RPostgres`, `dplyr`, `readr`, `zoo`, `ggplot2`, `tseries` and `forecast`, and EViews 10 or later.

> **Note on the simulator:** results are generated by transparent mathematical models seeded with deterministic sample
> data, so the same slider positions always give the same answer. They illustrate what the code computes; they are
> not real company or market data.

## Privacy

BizData Sandbox runs entirely on your machine. It collects no telemetry and makes no network requests.

## Building from source

```bash
git clone https://github.com/vgaseven/vg-hoster.git
cd vg-hoster/biz-data-sandbox
npm install
npm run compile
```

Press `F5` in VS Code to launch an Extension Development Host with the sandbox loaded.

### Packaging a `.vsix`

```bash
npm install              # installs TypeScript and @vscode/vsce locally
npx vsce package         # runs the compile step and writes biz-data-sandbox-0.1.0.vsix
code --install-extension biz-data-sandbox-0.1.0.vsix
```

### Publishing to the Marketplace

```bash
npx vsce login vgaseven  # paste an Azure DevOps Personal Access Token (scope: Marketplace → Manage)
npx vsce publish         # or upload the .vsix at https://marketplace.visualstudio.com/manage
```
