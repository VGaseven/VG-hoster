# Changelog

## 0.1.0

Initial release.

- **Open BizData Sandbox** command with a themed webview panel.
- Three business modules: Marketing Analytics (SQL + R), Corporate Finance (SQL + R) and Macro Forecasting
  (SQL + R + EViews).
- Editable code view with Reset, Copy and Open in editor actions.
- Live simulators with KPIs, charts and result tables; code parameters follow the sliders.
