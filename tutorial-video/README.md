# فيديو تعليمي: islamic-economics-cards.vercel.app

فيديو عربي مدته 20 ثانية بمقاس 1920x1080، يُسجَّل من واجهة الموقع الفعلية فقط.

## التشغيل

```bash
# 1) التسجيل: يفحص التسميات الحقيقية أولًا، ثم يسجّل اللقطات (بدقة 3840x2160)
node capture.cjs out
#    للفحص فقط بدون تسجيل:  node capture.cjs out --explore-only

# 2) المونتاج: تكبير على كل خطوة، وتعليق بسطر واحد، وتصدير MP4 وملف SRT
python3 compose.py out render/tutorial.mp4
```

المتطلبات: Playwright مع Chromium، وPython 3 مع Pillow (ومعه libraqm لتشكيل الحروف العربية)، وffmpeg،
والخط `fonts-noto-core` (يوفّر Noto Sans Arabic).

## الملفات الناتجة

- `out/report.json`: كل التسميات التي وُجدت فعلًا في الموقع، والخطة المختارة لكل لقطة (الأصلية أو البديلة)، وسبب التوقف إن توقف التسجيل.
- `out/probe/*.png`: لقطات شاشة من مرحلة الفحص.
- `render/tutorial.mp4` و`render/tutorial.srt`: الفيديو النهائي وملف الترجمة.
- `render/timing.json`: توقيت كل لقطة وسرعتها، و`render/qa/`: صور ثابتة للمراجعة.
